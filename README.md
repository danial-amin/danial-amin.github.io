# Danial Amin — portfolio revision

Text-driven portfolio with two A/B layouts:

- `/a` — Editorial Monograph
- `/b` — Field Notes Journal

Also: `/work`, `/writing` (essays + mirrored [AI Pulse & Data Waves](https://www.linkedin.com/newsletters/ai-pulse-data-waves-7201156885150871552/)), `/research` (teaser → [academic.danialamin.com](https://academic.danialamin.com/)).

## Develop

```bash
npm install
npm run dev
```

## Build / Railway

```bash
npm run build
npm start
```

Docker: see `Dockerfile`. Deploy on Railway and point `danialamin.com` when ready.

Legacy GitHub Pages site is archived under `_legacy/`.
